# Task 1: Iris Flower Classification

**Internship:** Oasis Infobyte, Data Science (Oct-Nov 2026)

## Objective
Classify iris flowers into Setosa, Versicolor, or Virginica using their measurements.

## Dataset
Built-in Iris dataset from scikit-learn (150 samples, 4 features).

## Steps
1. Loaded data and did EDA (shape, dtypes, nulls, statistics)
2. Visualised with pairplot and boxplots
3. Discussed feature selection (petal length and width are most useful)
4. Train/test split (80/20, stratified)
5. Trained Logistic Regression and Random Forest
6. Evaluated with accuracy, confusion matrix, classification report

## Results
| Model | Accuracy |
|---|---|
| Logistic Regression | 96.7% |
| Random Forest | 90.0% |

**Best model:** Logistic Regression

## Tools
Python, pandas, scikit-learn, matplotlib, seaborn, Google Colab
